# 거스름돈

- 문제 ID: `coin-change`. 거스름돈은 0원 이상 10,000원 이하이며 10원 단위로 주어진다.
- 목표는 500원, 100원, 50원, 10원 동전의 개수를 **각각** 구하는 것이다. 총 동전 수만 구하는 문제가 아니다.
- 학생 화면에는 문제와 기존 단계별 자연어 작성창만 제공한다. 조작 실습창, 시뮬레이션, 필수 버튼은 없다.
- 문제 이해 → 자연어 알고리즘 작성 → JEV 확인 → 배정된 동료평가 → 이유를 적고 수정하는 기존 연구 활동 흐름을 사용한다.
- 교사 체험: `/teacher/student-preview?problemId=coin-change`. 교사 콘솔의 문제 목록, 체험 활동 표, 시연 도구 아래 바로가기에도 추가했다.

## 채점

정답은 큰 동전부터 몫과 나머지를 구한 네 개수다(`changeCoins`). 네 개수가 모두 같아야 통과다. 일부 동전만 출력하면 실행은 되지만 오답이다.

고정 입력은 0, 10, 40, 50, 90, 100, 490, 500, 990, 10000이며 `coin-fixed-10-v1`로 저장한다. 0원, 각 동전 금액, 더 작은 동전만으로 채울 수 있는 최대 금액(40·90·490·990), 최대 금액을 포함한다. 단위 테스트는 0~10,000원 범위의 모든 10원 단위 금액(1,001개)에 대해 지원하는 풀이 형태를 검증한다. 유한 테스트 통과가 모든 입력에 대한 증명은 아니다.

## 해석 (`coin-program-v1`)

JEV는 문장 하나마다 네 가지를 함께 고른다.

| 질문 | 값 |
| --- | --- |
| `action` | 닫힌 명령 집합(`COIN_ACTIONS`) |
| `coin` | 500·100·50·10원, 반복 중인 현재 동전, 정할 수 없음 |
| `source` | 나누거나 비교하거나 빼는 금액: 주어진 거스름돈 / 별도의 남은 금액·나머지 |
| `target` | 나머지나 뺀 결과를 저장하는 금액 |

동전과 금액을 별도로 묻기 때문에 학생이 `M`, `x`, `받을 돈`, `a`, `500원 개수`처럼 어떤 이름을 써도 된다. 정해진 문구나 변수 이름을 따라 쓰도록 요구하지 않는다. 주어진 거스름돈은 따로 정하지 않아도 된다.

지원 풀이:

- 나눗셈: 몫을 개수로, 나머지를 금액으로(한 문장 또는 두 문장), 개수×동전 금액 빼기, 몫을 바로 출력.
- 별도의 남은 금액: `r = M % 500`처럼 나머지를 다른 값에 저장하고 이어서 사용. 이후 원래 거스름돈을 다시 나누면 원래 값 그대로 계산한다(풀이를 고치지 않음).
- 동전 반복 사용: `~인 동안 주고 빼기를 반복`, 반복 시작/끝 단계, `N단계로 돌아간다`, 조건부 1회 주기.
- 동전 종류마다 반복: 문장에 적힌 순서(`500원부터 10원까지`, `큰 동전부터`, 금액 나열)대로 실행한다. 작은 동전부터 쓰면 그 순서대로 실행해 오답이 된다.
- 출력: 한 동전 개수, 문장에 적힌 여러 동전, 네 동전 모두.

보충하지 않는 것: 개수 기록에 1을 더하는 풀이의 처음 값, 생략된 반복, 생략된 나머지 갱신, 계산하지 않은 개수의 출력. "동전을 준다"는 실제로 준 개수를 세므로 처음 값이 필요 없다.

## 검사 보류

다음은 오답이 아니라 검사 보류로 기록하고 테스트를 실행하지 않는다.

- `NONE` 또는 확신도 0.65 미만
- 동전이나 금액을 하나로 정하지 못함
- 문장에 쓴 동전 금액과 해석한 동전이 다름
- 동전 종류마다 반복하는 범위 밖의 "그 동전"
- 반복 순서나 돌아갈 단계 번호를 문장에서 확정하지 못함

API 실패와 형식이 잘못된 응답은 실패 상태와 재시도로 처리한다. 모델 응답은 코드로 실행하지 않는다.

## 결과 표시

결과 저장 형식은 기존과 같고 `expected`, `output`이 네 개수 배열이며 `answerLabels`(`500원`…`10원`)가 붙는다. 결과 카드는 사례별 요약에 네 개수를 나란히 보여 주고, 펼치면 동전별 제출·정답·일치 여부 표와 단계별 금액·개수 기록을 보여 준다. 엑셀 내보내기에서는 배열 값을 JSON 문자열로 기록한다. 기존 단일 숫자 활동의 표시는 바뀌지 않는다. 교사 일괄 AI 실행(상자 문제 전용)은 이 변경에 포함하지 않았다.

## 검증 범위

JEV 응답은 테스트에서 가짜 서비스로 대체했다. 실행기, 해석 보류 규칙, 저장, 체험, 수정 전후 결과 보존을 검증하며 실제 JEV 모델의 한국어 분류 정확도를 보장하지 않는다. 운영 반영 후 교사 체험으로 실제 해석을 확인해야 한다.
