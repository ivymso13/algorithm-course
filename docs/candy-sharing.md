# 사탕 나누기

- 문제 ID: `candy-sharing`. 입력 N은 1~10,000인 정수다.
- 학생 화면에는 문제와 기존 단계별 자연어 작성창을 제공한다. 조작 실습창과 허용 행동 버튼은 없다.
- 첫 제출 고정, JEV 확인, 배정된 동료평가, 수정 이유와 버전 이력은 기존 연구 활동 흐름을 사용한다.
- 교사 체험: `/teacher/student-preview?problemId=candy-sharing`.

## 채점

정답은 `k(k+1)/2 <= N`을 만족하는 최대 정수 k다. 남는 사탕은 가장 많이 받은 친구에게 더 줄 수 있으므로, 실제 배분 과정을 요구하지 않는다.

JEV는 학생의 명시적인 문장만 닫힌 명령 집합으로 분류한다. 코드 실행기는 초기화, 덧셈/뺄셈, 조건과 반복, 수식과 출력을 실행한다. 모델이 반환한 문자열을 코드로 실행하지 않는다. 누락된 초기값, 출력, 반복 본문을 채우거나 수식의 오류를 수정하지 않는다. 미지원 표현이나 낮은 확신은 검사 보류이며 오답이 아니다. API 실패는 별도 실패 상태와 재시도로 처리한다.

반복형은 누적 합/남은 사탕, 친구 수, 다음 수를 기록하는 방법을 지원한다. `동안 반복`의 시작과 끝 또는 돌아갈 이전 단계 번호를 명시한다. 공식형은 제곱근 식의 내림, 올림, 정수 처리 없음과 삼각수 부등식의 최대 정수 조건을 구분한다. 모든 자유로운 표현이나 임의의 계산식을 해석하는 범용 실행기는 아니다.

고정 입력은 1, 2, 3, 5, 6, 8, 9, 10, 9999, 10000이다. `candy-fixed-10-v1`로 저장한다. 단위 테스트에서는 범위 전체의 정답과 삼각수 경계 앞뒤를 별도로 검증한다. 이 유한 테스트를 통과하는 것이 모든 입력에 대한 증명은 아니다.

## 명시적인 작성 예

반복형:

1. 친구 수 k를 0으로 정한다.
2. 누적 합 s를 0으로 정한다.
3. 다음 수 a를 1로 정한다.
4. s+a가 N 이하인 동안 다음 단계들을 반복한다.
5. s에 a를 더한다.
6. k에 1을 더한다.
7. a에 1을 더한다.
8. 반복 본문을 끝내고 조건으로 돌아간다.
9. k를 출력한다.

공식형:

1. k를 (√(8N+1)-1)/2에서 소수 부분을 버린 정수로 계산한다.
2. k를 출력한다.

학생 화면에 이 예시를 정답 템플릿으로 제공하지 않는다. 교사 체험의 예시 동료 자료에는 등호가 빠진 반복 풀이와 정수 처리가 명시된 공식 풀이를 사용한다.

## 검증 범위

자동 테스트의 JEV 응답은 가짜 서비스로 대체한다. 실행기와 저장·권한·체험·수정 흐름의 검증이며, 실제 JEV 모델의 한국어 문장 분류 정확도를 보장하지 않는다. 운영에서 교사 체험으로 해석과 원문 일치 여부를 확인할 수 있다.
