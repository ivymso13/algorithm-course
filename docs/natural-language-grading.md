# 자연어 배분·적재 해석 보완

사탕 `candy-program-v2`, 트럭 `truck-actions-v2`는 학생이 제시한 배분 표현과 조건부 복합 행동을 지원한다. 지원하지 않는 표현과 낮은 확신은 학생의 오답으로 단정하지 않고 검사 보류로 안내한다. 해석 후보가 NONE일 때 내부 분류 지침을 학생에게 그대로 노출하지 않는다.

## 트럭

- 합계가 10kg 초과일 때 출발하고 새 트럭에 싣는 조건부 복합 행동을 지원한다. 출발과 싣기는 같은 조건 아래 실행한다.
- 그렇지 않으면 현재 트럭에 싣는 분기는 학생이 실제로 작성했을 때만 실행한다.
- 트럭 수 확인은 사용한 실제 트럭 수(출발한 트럭 + 적재 중인 트럭)를 관찰하는 행동이다. 정답 출력은 별도 행동이다.
- 동일 상자 중복 적재와 미적재 상자가 있는 종료를 검사한다.
- 이전 제출 버전의 결과는 보존한다. 새 제출 버전부터 보완된 해석을 적용한다.

> 만약 현재 상자 무게와 현재 적재 무게의 합이 10kg보다 크다면 트럭을 출발시키고 새 트럭에 싣는다.

초과하지 않을 때의 싣기를 의도했다면 해당 행동도 명시해야 한다. 해석기가 학생 문장을 올바른 풀이로 바꾸어 실행하지 않는다.

테스트는 학생이 제시한 문장, 조건이 거짓인 사례, 참인 사례, 명시된 양쪽 분기, 실제 트럭 수 관찰, 중복·누락 적재, 수정 전후 원문과 결과 보존을 포함한다. JEV 응답은 모의 서비스로 검증한다. 운영 비밀값은 조회 시 가려지므로 실제 API의 분류 정확도를 이 테스트만으로 보장하지 않는다.
